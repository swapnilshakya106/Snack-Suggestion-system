# Snack-Suggestion-system
A simple Python project that suggests snacks based on time of day and food preference.

This is a simple Python project I made to practice basics like if-else, lists, and the random module.

What it does

This program asks the user:

What time it is (morning/afternoon/evening/night)
What they want to eat (veg/nonveg/sweet)

Based on the answers, it suggests a random snack from a list.

How to run:
 1. Make sure Python is installed on your system.
 2. Download or clone this repository
 3. oopen terminal in the project folder and run. [python snack_suggestion_beginner.py]
 4. Answer the question and get your snack suggestion.

What is learned:
1. Using if-elif-else Statements
2. Working with lists
3. Using the random module(random.choice)
4. Talking input from the user
